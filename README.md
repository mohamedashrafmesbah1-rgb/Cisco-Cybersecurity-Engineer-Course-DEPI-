# 🌐 Cisco Cybersecurity Engineer — DEPI Final Project

This repository contains my final project for the **Cisco Cybersecurity Engineer Course** at the **Digital Egypt Pioneers Initiative (DEPI)** — an enterprise network design and configuration project built and validated in Cisco Packet Tracer.
